# kuaima-web-static

快马日结静态 Web 版。

## 目录说明

- `index.html`：入口页面
- `styles.css`：样式
- `app.js`：交互逻辑
- `static/`：静态资源
- `404.html`：静态托管 SPA 回退页

## 本地预览

直接打开 `index.html`，或用任意静态服务器托管。

## 静态托管建议

- 构建输出目录：项目根目录（当前仓库根）
- 首页：`/index.html`
- 404：`/404.html`
- 支持 hash 路由，可直接访问如 `/#worker`
