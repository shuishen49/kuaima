# 产品经理拆解（静态 Web 版）

## 目标
把 `kuaima` 的 uni-app 小程序界面迁移为可直接部署到 EdgeOne Pages 的静态前端站点（无后端依赖）。

## 范围
- 角色选择页（零工/老板）
- 零工端：首页 / 订单 / 消息 / 我的
- 老板端：首页 / 订单 / 消息 / 我的
- 统一底部 TabBar 导航
- 保留品牌风格与核心文案

## 非目标
- 不接入登录、定位、支付、聊天等真实后端功能
- 不实现小程序能力（如 `uni.*` API）

## 交付物
1. `index.html`（单页应用入口）
2. `styles.css`（视觉与布局）
3. `app.js`（前端路由与交互）
4. `docs/UI_GUIDE.md`
5. `docs/QA_CHECKLIST.md`

## 验收标准
- 本地 `file:///.../index.html` 可直接打开
- 页面间可切换，主要按钮有交互反馈
- 移动端宽度下（375~430）布局不崩
- EdgeOne Pages 上传后可直接访问

## 风险与对策
- 风险：静态环境下无 API，页面信息可能“空”。
  - 对策：提供演示数据与占位内容，明确“静态演示”。
- 风险：小程序样式到 Web 存在差异。
  - 对策：统一使用 CSS 变量 + 卡片化布局，优先保证观感一致性。

## 里程碑
1. 信息架构完成
2. UI 框架完成
3. 交互联调完成
4. QA 自测通过
5. 可部署包输出
