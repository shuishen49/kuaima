# UI 设计说明（静态 Web 版）

## 设计原则
- 黄系品牌主色（快马日结）
- 卡片化信息层级
- 移动优先（最大宽度 430）
- 大按钮、粗标题、强对比

## 颜色
- 主色：`#FFCC00`
- 强调：`#FF6B00`
- 背景：`#F6F8FB`
- 卡片：`#FFFFFF`
- 次文案：`#667085`

## 组件
- Hero 区块：角色核心价值主张
- Action Card：当前页主转化按钮
- Stats Grid：功能入口与指标
- TabBar：底部四栏导航
- Empty State：无数据占位

## 可用性要求
- 所有可点击元素 hover/active 有反馈
- 文本不小于 12px
- 页面滚动区域清晰
- 底部导航始终可见

## 适配
- 360/375/390/414/430 宽度优先
- `safe-area-inset-bottom` 兼容 iOS 刘海屏
